Achilles is a vertical scroller we developed for the Game Design Studio 3 course. The project started from a set of draft game mechanics that were given to us. Our job was to build those mechanics in the engine, bring the game to a visually polished state, and learn along the way how a vertical scroller is actually made.

Since it was a short project, we treated it as a chance to gain as much experience as possible in a limited time. We kept the project management tight and worked closely as a team from start to finish, which made Achilles as much an exercise in teamwork and planning as in game development.

On the production side, the project gave me hands-on experience with the core components that make a game feel complete: VFX, SFX, UI and camera. These are the parts that turn working mechanics into something that looks, sounds and plays like a finished game, and Achilles was where I practiced using them together.

On the design and programming side, I learned about the concepts underneath the game: how a gameplay loop is structured, how enemy AI behaves, and how state machines are used to organize that behavior.

Achilles was a small project, but it taught me a lot about both building a game and working in a team to finish one.
