Color Shift is a color-based puzzle platformer we developed for the DGD303 Game Engines 2 course at İstinye University. We worked on it as a team of three for about two months, and it is currently a playable prototype for Windows.


The game is built around one idea: color decides how you interact with the level.Each level asks the player to work out the right order of color changes to reach the exit, so the challenge comes from thinking as much as from jumping.

As the game designer and programmer, I designed the core color mechanic and the levels, and programmed the player controller and the color system.

The course was about using the engine properly, so we built the game as a complete flow instead of a single test scene: a main menu, a level select screen and the levels themselves.


Color Shift is still a prototype, but it taught me how to take one simple mechanic and build levels, menus and a full game structure around it as a team.
